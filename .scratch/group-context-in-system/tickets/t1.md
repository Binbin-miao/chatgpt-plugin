## 改动 1：`collectGroupContext` 返回值拆两段

`model/core.js:186` 的 `result` 增加 `stable: ''`。

群聊路径（`groupId` 存在时）：

- `result.stable` = 用 `<group_context>…</group_context>` 包住的 `publicText`（`\nthe group name is X, group id is Y。Your nickname is Z in the group,There is the conversation history in the group...` + 群记录各行）。标签只在 `collectGroupContext` 出口加一次，缓存里仍存不带标签的原文，逐字节比较不受影响；`publicText` 以 `\n` 开头，拼接前需 `trimStart()`，否则标签后会出现空行。
- `result.turn` = `Attention, you are currently chatting in a qq group.\nThe one who asks you now is 名字(qq号)。`

私聊路径保持现状：`result.stable` 留空串，`result.turn` 不变。

`groupContextBody(group)`（:312）**不改**，仍是 `[group.tip, group.turn]`。

## 改动 2：快照重建判定

替换 `:230-279` 的「`at + ttl` 过期」逻辑为：

```
cached = groupSnapshotCache.get(snapshotKey)
if (cached && Date.now() - cached.at < 30_000) → publicText = cached.text（直接复用，不拉取）
else:
  chats = await msgHistoryMgr.getGroupHistoryContext(e, groupContextLength, { fromLatest: true })
  threshold = Math.max(3, Math.ceil((chats?.length || 0) / 3))     // 拉满 60 条 → 20
  newer = 比 cached.newestMessageId 更新的条数
          （在 chats 里 findIndex 找该 id；索引 < 0 表示旧 id 已滑出窗口 → newer = chats.length）
  if (!cached || newer >= threshold) → 重建 publicText，写入 { text, at: Date.now(), newestMessageId, full }
  else                                → publicText = cached.text
```

- `newestMessageId` 取 `chats[chats.length - 1].message_id`，用 `String()` 归一。
- 删除 `GROUP_SNAPSHOT_TTL`、`GROUP_SNAPSHOT_EMPTY_TTL` 常量，改为 `GROUP_SNAPSHOT_MIN_INTERVAL = 30_000` 与 `GROUP_SNAPSHOT_MIN_NEW = 3`。
- **拉取抛错或返回空**：有缓存时沿用 `cached.text`，不得清空或缩短。首次构建拉不到记录时，仍生成只含群名/群号/群名片的快照（这三样本机就有，丢掉只会让 system 变短），`newestMessageId` 记空串。
- **两套时间戳必须分开**：频率保护用 `fetchedAt`（上次实际拉取时刻，拉取成功即续期，不论是否重建）；内容新旧只看 `newestMessageId`。把两者混成一个字段，会让活跃群永远卡在 30 秒窗口内、`chats` 恒为 null、快照终身不重建。

## 改动 4：抽两个纯函数并导出（供 t2 单测）

```js
export function rebuildThreshold(count) { return Math.max(3, Math.ceil((count || 0) / 3)) }

export function countNewerMessages(chats, lastId) {
  if (!Array.isArray(chats) || chats.length === 0) return 0
  if (!lastId) return chats.length
  const idx = chats.findIndex(c => String(c?.message_id ?? '') === String(lastId))
  return idx < 0 ? chats.length : chats.length - idx - 1
}
```

`collectGroupContext` 本身也加 `export`（不改签名），便于后续集成测试。
